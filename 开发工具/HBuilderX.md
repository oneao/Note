## 创建Demo项目

点击 文件 -> 新建 -> 1.项目
输入项目名称和选择项目模版

## 修改运行设置

### 修改默认浏览器
点击 工具 -> 设置 -> 运行设置 -> 浏览器运行设置 -> 设置安装路径

### 修改微信小程序
点击 工具 -> 设置 -> 运行设置 -> 微信开发者工具设置 -> 设置安装路径（直接精确到 exe）
当更新 HbuilderX 的时候，重新点击微信小程序的 编译 即可。
点击目录中的 `mainfest.json`，选择 微信小程序配置 填写对应的 `appid`
### 修改微信开发者工具
点击 右上角的设置 -> 安全 -> 开启服务端口
