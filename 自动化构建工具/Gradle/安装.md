## Linux安装Gradle
> 基于Kali系统

下载官网：[https://gradle.org/releases/](https://gradle.org/releases/) 或者 [https://services.gradle.org/distributions/](https://services.gradle.org/distributions/)
下载 `xxx-all.zip`，解压使用即可。

**配置环境变量**
在`~/.zshrc`文件中添加以下内容：
```
export GRADLE_HOME=/home/oneao/Devtool/gradle-8.8
export PATH=$PATH:$GRADLE_HOME/bin
```
刷新
```bash
source ~/.zshrc
```
验证
```bash
gradle -v
```

## Windows安装Gradle
下载官网：[https://gradle.org/releases/](https://gradle.org/releases/) 或者 [https://services.gradle.org/distributions/](https://services.gradle.org/distributions/)
下载 `xxx-all.zip`，解压使用即可。

添加环境变量
```
在系统变量中新建 GRADLE_HOME      D:\Gradle\gradle-5.6.1
在Path新建 Path        %GRADLE_HOME%\bin
```

打开`cmd`输入`gradle -v`查看是否安装成功
